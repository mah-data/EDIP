# EDIP Architecture Overview

## Introduction

EDIP (Enterprise Data Intelligence Platform) is a metadata-driven platform designed to manage and organize data assets from different data sources.

The first version focuses on establishing the foundation for data source management, dataset registration and data quality rule definition.

---

## Version 1 Scope

Version 1 provides the following capabilities:

- Data Source Management
- Connection Management
- Dataset Management
- Data Quality Rule Definition
