
# ADR-001

## Title

Project Repository Structure

## Status

Accepted

## Context

The EDIP project requires a clear, maintainable, and scalable repository structure to support documentation, database scripts, Python development, testing, and future expansion.

## Decision

The project repository will use the following structure:

EDIP/

docs/

architecture/

database/

diagrams/

requirements/

sql/

python/

tests/

sample-data/

scripts/

README.md

## Consequences

Advantages

- Clear project organization
- Easier maintenance
- Supports team collaboration
- Scalable for future modules

Disadvantages

- Slightly more folders at the beginning
