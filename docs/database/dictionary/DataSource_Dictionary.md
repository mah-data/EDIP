# DataSource Dictionary

| Column | Data Type | Description |
|---------|-----------|-------------|
| DataSourceID | INT | Unique identifier |
| SourceName | NVARCHAR(200) | Business source name |
| SourceType | NVARCHAR(100) | Source category |
| Owner | NVARCHAR(200) | Business owner |
| Status | NVARCHAR(50) | Current status |
| Description | NVARCHAR(1000) | Additional information |
| CreatedDate | DATETIME2 | Creation date |
| CreatedBy | NVARCHAR(100) | Creator |
